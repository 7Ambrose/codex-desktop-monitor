# Codex 桌面任务监控

## 组合方案

日常状态与用量显示复用 [Codex Monitor HUD](https://github.com/LH-03/codex-monitor-hud)，本项目补充按需 GPT 复核及操作确认。固定版本、校验值和职责见 [第三方组件说明](THIRD_PARTY.md)。HUD 的暂停只暂停显示更新。

优先速度与省用量：基础监控零模型调用；连续相同失败或手动请求才复核；GPT-6 Luna、低推理、每轮最多一次、间隔至少十分钟、每日最多十次。此模式不会自动发现每一种偏题，重要交付可手动复核。

在 Codex 桌面端继续聊天，由本机后台记录生命周期事件，独立 GPT 按需检查偏题、重复失败和交付依据。提供中文面板，异常时在下一次工具操作前请求确认。

## 当前边界

- **操作确认不等于整项任务已中断。** 当前桌面进程没有已验证的外部控制连接；本项目使用官方 MCP Hook 和 elicitation 确认，在下一个工具调用前等待用户。已经启动的命令可能继续运行。
- 在客户端提供确认能力且钩子已受信任时，确认窗口才可用。没有确认能力则明确拒绝该次工具调用，不能宣称整个模型循环已停止。
- Codex 官方 Hooks 对错误和超时可能放行；本项目不是不可绕过的权限或安全隔离系统。监控连接失败时会提示，不能假装仍受保护。
- 独立 GPT 只审核收到的材料；未读取内容、未渲染的版式和不完整工具结果均不能算验证通过。
- 文件内容检测目前限于输出路径存在性和少量文本摘录。Word、PDF 等只检查文件元数据，尚未接入内容和版式渲染验收。
- 页面中的 CPU 是后台 Python 服务的单核使用率，不包含 Codex 子进程或浏览器。正式占用报告应分别测量这些进程。

## 使用

需要 Python 3.11+ 和可以正常登录的官方 Codex CLI。没有第三方 Python 包依赖。

1. 运行 `python configure.py prepare`，生成本地设置和待审核的安装定义。
2. 检查 `.local/hooks.proposed.json` 与 `.local/config.proposed.toml`。
3. 运行 `python configure.py install`，可逆地合并 MCP 和钩子配置。其他配置会保留，原件备份在 `.local/backup-*`。
4. 双击 `打开监控.cmd`，启动后台并打开本机面板。
5. 按 Codex 官方流程审核并信任新钩子，再在桌面端开始新任务。仅安装配置不代表钩子已信任、已触发或已完成真实任务验收。

Windows 可运行 `install_windows.ps1` 完成同样的安装并创建桌面入口 `Codex Monitor` 和登录启动项。启动项只运行本地服务，不会在登录时调用模型。

通过 `settings.local.json` 配置工作文件夹、排除的聊天、复核模型和频率。空的 `enabled_roots` 表示尚未启用监控范围。安装程序首次准备时以项目所在父文件夹为默认范围，应按实际需要检查。

卸载定义：`python configure.py uninstall`。该操作只移除本项目的配置段和钩子，保留其他设置与任务文件。自动启动如另行配置，需要同时移除对应启动项。

## 独立复核

默认通过 `codex exec` 使用官方保存的登录状态，不读取或复制登录令牌，不要求将账号凭据写到项目中。使用临时只读会话、关闭钩子和不必要的工具能力；复核出现工具调用则废弃结果。额外调用会消耗相应模型用量。

默认使用省用量模式：普通回答结束不会调用模型，只有连续相同失败或用户手动请求时复核。默认 GPT-6 Luna、低推理强度、标准速度；GPT-5.6 Luna 是可手动选择的备选，不自动升级到更贵模型。内置较短的专用复核指令替代通用编码指令，并对送审材料限长。

默认每轮最多 1 次、自动复核间隔至少 10 分钟、每天总计最多 10 次（包括手动和失败尝试）。同一聊天只保留一个排队复核，过期结论不能控制新轮次。复核不可用时显示不可用，不能记为通过。可在本地设置中改为 `balanced`（文件交付时复核）或 `comprehensive`（每轮结束复核）。

## 数据与访问

- 数据库、访问令牌、运行日志、模型审核临时文件和安装备份均放在 `.local/`，Git 忽略。
- 个人设置使用 `settings.local.json`，Git 忽略。仓库只包含默认示例。
- HTTP 只监听 `127.0.0.1`，任务数据和控制操作需要本机随机令牌，并核查 Host 和 Origin。
- 默认保留最近 7 天日志；已知密钥格式会被遮盖，但不承诺能识别任意格式的秘密。
- 不从运行日志推测订阅总账或人民币费用。
